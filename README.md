# Reinforcement Learning-Based IAS Dosing Strategy

This project proposes a reinforcement learning (RL)-based method to derive personalized treatment strategies, as an alternative to the simple dosing approach (which simply administers or withdraws medication based on fixed PSA thresholds). The feasibility of this method is tested using Takagi-Sugeno fuzzy modeling, and a suitable condition under which the action-induced dynamical system allows this method to take effect is identified. Numerical simulations demonstrate that the strategy generated by the RL agent can delay biochemical progression while reducing the total medication amount, compared to the simple on-off rule.
